# Champ Select Tools changelog

## 0.2.0 - 2026-10-15

### Changed
- Settings moved to maoloader's shared settings window: Ctrl+K → **Plugin settings** → Champ Select Tools. Your saved settings carry over. Changing settings needs maoloader 0.1.7 or newer.
- New **Show the HUD** switch in settings; before, only a Ctrl+K command could change it.

## 0.1.0 - 2026-10-15

First release. A champ select HUD with the phase timer, auto pick and ban, random skin, ARAM reroll, and a dodge button that needs a second click.
