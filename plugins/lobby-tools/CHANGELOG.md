# Lobby Tools changelog

## 0.2.0 - 2026-10-15

### Changed
- Settings moved to maoloader's shared settings window: Ctrl+K → **Plugin settings** → Lobby Tools. Your saved settings carry over. Changing settings needs maoloader 0.1.7 or newer.

## 0.1.0 - 2026-10-15

First release. Create any available queue's lobby from the command bar, start or stop queue, and play again or re-queue after games.
